# RSJP Experience System — SEO and Discoverability Specification

## Objective

Help prospective students find accurate programme information through search and social sharing without compromising writing quality.

## Principles

- Search intent before keyword density.
- Accuracy before traffic.
- Useful titles before clever titles.
- One clear canonical representation per page.
- No fabricated claims, rankings, or statistics for SEO.

## Search Intent

Important likely intents may include:

- Ritsumeikan short-term Japanese programme,
- study Japanese in Japan,
- short-term study abroad at Ritsumeikan,
- programme-specific searches,
- accommodation / fee / application searches.

Do not create pages solely for speculative keywords without user value.

## Titles

Each indexable page should have a descriptive unique title.

Title should communicate the actual page topic.

Avoid repeating one generic title across the site.

## Meta Descriptions

Write concise, factual summaries.

Do not stuff keywords.

Do not promise unavailable features or outcomes.

## Headings

Use one logical page heading.

Heading structure should serve readers first.

Do not distort content hierarchy for SEO.

## URLs

Prefer:
- readable,
- stable,
- short,
- language-consistent paths.

Avoid unnecessary implementation detail in URLs.

Do not change established URLs casually; redirects and migration impact must be considered.

## Canonical URLs

Use canonicals where appropriate to prevent duplicate representations.

Do not canonicalise different programme content to one page merely for convenience.

## Open Graph / Social

Provide accurate:
- title,
- description,
- image,
- URL.

Use authentic programme imagery.

Do not use misleading social-preview copy.

## Structured Data

Use schema.org structured data only when the page genuinely matches a supported type.

Do not fabricate:
- ratings,
- reviews,
- event availability,
- organisation claims.

Validate structured data before relying on it.

## Images

Use descriptive filenames where practical and meaningful alt text for accessibility.

Alt text is not a keyword field.

## International / Multilingual SEO

When multiple language versions exist:

- keep facts consistent,
- use appropriate language metadata,
- consider `hreflang` once routes/languages are stable,
- avoid machine-generated duplicate pages without editorial quality.

Do not implement `hreflang` until actual URL relationships are known.

## Indexing

Do not index:
- unfinished placeholders,
- internal admin/test pages,
- duplicate drafts,
- pages containing unconfirmed placeholder programme facts.

Use repository/deployment mechanisms appropriate to the environment.

## Performance

Core performance affects discoverability and user experience.

Prefer:
- static rendering,
- responsive images,
- stable layout,
- minimal JS.

## Content Quality

SEO must not produce repetitive unnatural copy.

Do not write pages merely to satisfy keyword variants.

## Measurement

Use analytics/search tools only when approved and available.

Do not invent baseline traffic or conversion metrics.

## SEO Review

Check:

1. Does the page answer a real search/user need?
2. Is title unique and accurate?
3. Is description factual?
4. Is heading hierarchy logical?
5. Is canonical correct if needed?
6. Is social preview accurate?
7. Are images optimised?
8. Is any structured data truthful and valid?
9. Is the page worth indexing?
