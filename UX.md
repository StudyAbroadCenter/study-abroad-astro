# RSJP Experience System — Operational UX Rules

The UX should reduce uncertainty and make the next decision obvious.

## Primary Journey

A first-time prospective student should be able to move naturally through:

1. understand what the site/programme is,
2. identify the right programme,
3. understand experience and academic value,
4. check dates, duration, fee, status, and eligibility,
5. understand accommodation and practical conditions,
6. resolve common concerns,
7. apply or contact the correct team.

Do not force users to understand internal university structure before taking these steps.

## Essential Information

Do not bury:

- programme dates,
- duration,
- fee,
- application status,
- application period,
- eligibility,
- accommodation conditions.

Essential facts should be visible or reachable with minimal interaction.

## Progressive Disclosure

Show in this order:

1. decision-critical information,
2. useful explanation,
3. deeper operational detail,
4. special conditions/policies.

Do not present all administrative detail at once.

## Navigation

Navigation must be:

- shallow,
- predictable,
- consistent,
- easy to scan on mobile.

Avoid menus organised primarily by internal departments.

## CTA

Each important page should have one clear primary next action where possible.

Examples:

- Apply Now
- View Programme
- Check Dates and Fees
- Read Application Guidelines
- Contact Us

Do not create competing primary CTAs without a user need.

## Mobile

Assume the first visit may happen on a phone.

At 390px, users must be able to:

- identify the programme,
- see status,
- understand the key value,
- find essential facts,
- find the primary CTA.

## Forms

Ask only for information genuinely required.

Use clear labels, visible validation, and understandable recovery messages.

## Uncertainty

If information is not yet available, say so clearly.

Never fill an empty state with invented programme data.

## UX Test

Before approving a page, ask:

- What question brought the student here?
- Can they answer it quickly?
- What is the next likely question?
- Is the next action obvious?
- Is any institutional complexity unnecessary?
